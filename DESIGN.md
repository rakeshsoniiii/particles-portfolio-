# Captured design system

Derived from the original page DOM, styles and browser observations, following the design-document approach in `temp-refrence/awesome-design-md`.

- Background: `#222124`; foreground: `#f0f2f0`; muted: `#8b8f8c`.
- Accent tokens: `#f4ce15` and `#379777`.
- Font: locally hosted Inter Tight; regular body and medium headings.
- Main content width: 90vw. Introductory scenes occupy 100svh each.
- Hero labels: horizontally opposed in landscape; top-left/bottom-right in portrait.
- `.t-30`: 1.5625vw / 1.82292vw landscape; 3.05556vh / 3.56481vh portrait.
- Fixed Three.js particle canvas sits beneath the content. A fixed moving noise layer adds texture.
- Portfolio is driven by vertical scroll moving a horizontal video track; it is not a button-driven carousel.
- Preserve original CSS orientation queries, shaders, timing, typography and assets. Do not substitute decorative approximations.
